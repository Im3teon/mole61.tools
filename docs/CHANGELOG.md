# 更新紀錄
## 摩界之門採集（本機版本）
- 使用 `撈金魚/bin/ForestHarvest3/撈金魚.exe`，在「休閒與日常」按「摩界之門採集」。
- 自動從主世界地圖前往黑森林／雲霧謎橋，再開啟黑森林地圖進入摩界之門，依序採集毛毛豆種子、拉姆菌、右下角紫色怪獸的捕蠅草種子。
- 留空會將三項各採到上限；輸入 1～999 則各採指定回數，遇到上限提早切換或結束。一回以確認的獎勵提示計算。
- 固定座標點擊，不使用 OCR。拉姆菌採集前會先移開角色，避免角色遮擋採集點；自動關閉獎勵與上限提示，失敗時有限次重試、停止並保存診斷截圖。
- 可按計數視窗的「停止」中止。未知提示或角色資料卡會停止並保留畫面；完成後停留在摩界之門。
- 2026-10-12 已在登入中的 Flash 實測進圖、兩種物品取得、獎勵關閉與上限切換。最後一輪自動流程確認毛毛豆已達上限，連續取得 7 回拉姆菌，再確認兩項上限並關閉遊戲提示。

## 彩虹瀑布採收螢火草（本機版本）
- 修正從家園開啟漿果叢林地圖時被判成未知畫面的問題：改用地圖內部兩個不透明區域判斷，排除後方場景差異；入口仍直接點擊 X:288、Y:206，不使用 OCR。
- 修正從家園開啟漿果叢林地圖時被判成未知畫面的問題：改用地圖內部兩個不透明區域判斷，排除後方場景差異；入口仍直接點擊 X:288、Y:206，不使用 OCR。
- 修正取得獎勵跳窗：補入實際遊戲字體的固定訊息與物品名稱比對，不依賴獎勵數量。自動點擊「知道了」並確認關閉，未生效時最多嘗試三次；重新啟動採收可先關閉既有獎勵跳窗，不重複計次。
- 已移除 OCR 與入口圖示搜尋，改回點擊遊戲內容像素座標 X:288、Y:206；入口座標不再套用 960×560 縮放。其他錄影中的路線座標保留原有換算。
- 點擊使用正確的滑鼠按下旗標，並保留短暫按住時間；仍有地圖穩定等待及最多三次重試。
- 修正實際診斷截圖中每日上限提示的辨識；已達上限時直接確認並停止，不再回報進圖失敗。
- 發生錯誤時，會將遊戲截圖、最後點擊的內容／視窗座標及畫面狀態存於程式旁的 `diagnostics` 資料夾。
- 在「休閒與日常」點選「採收螢火草」，會從主世界地圖開啟漿果叢林，再前往彩虹瀑布；已在目的地可直接採收。
- 輸入 1～999 可指定採收回數；留空會採到遊戲顯示每日上限。一回是一次已辨識的獎勵提示，不代表一株草或一次滑鼠點擊。
- 自動確認錄影中出現的獎勵、每日上限及「已經在這裡」提示；達每日上限會提早停止，完成後留在彩虹瀑布。
- 採收期間可按計數視窗的「停止」或關閉計數視窗中止，也可用 Ctrl + Backspace 結束程式。
- 地圖及採收均有等待上限；不認識的標準提示會保留畫面並停止。辨識依據為提供的錄影，其他版本或不同獎勵文字可能需要補充樣本。
- 2026-10-12 已實測自動進入彩虹瀑布、觸發每日上限並自動關閉提示；當日額度已用完，未實測取得新螢火草獎勵。
