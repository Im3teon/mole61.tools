# 螢火草功能驗證

使用 Visual Studio MSBuild 建置 `FireflyGrass.Tests.csproj`，再執行 `bin/FireflyGrass.Tests.exe`。測試不會啟動遊戲、模擬滑鼠或連線帳號，無需額外 NuGet 套件。

涵蓋自動路線、入口點擊失效重試、地圖穩定等待、載入期間不重點、已在目的地、延遲關閉提示、依獎勵計次、每日上限、未知提示、取消、輸入範圍與等待逾時。

可將已擷取並正規化的錄影影格目錄作為第一個參數，額外檢查畫面辨識：

```powershell
./tests/bin/FireflyGrass.Tests.exe .video-analysis/normalized
```

影格以 `frame-01.png` 至 `frame-37.png` 命名：本機錄影 `2026-10-11 23-01-55.mkv` 以 ffmpeg `fps=1,scale=1440:-1` 擷取，再以 `crop=1399:810:0:0,scale=960:560` 去除右側黑邊並正規化。完整錄影及影格不加入專案；程式僅嵌入辨識所需的局部樣本。

影像驗證包含 18 個影格、720/960/1440 三種寬度，以及空白畫面和不明提示。這些檢查驗證錄影中的 UI 辨識與模擬流程，不能取代實際遊戲對點擊及等待時間的端到端驗證。

可提供第二個參數指定實際每日上限截圖，驗證該次失敗畫面能正確辨識。現行版本不使用 OCR，也不需要 Windows OCR SDK。

第三個及後續參數可傳入取得獎勵截圖，檢查不同尺寸、獎勵數量區域移除及物品名稱缺失；另模擬「知道了」首點未生效、持續未關閉及上次遺留獎勵跳窗，確保重試有上限且不重複計次。

另可追加 `--berry-map <截圖路徑>`，驗證從家園開啟漿果叢林地圖的實際失敗截圖（三種尺寸），並將辨識結果接到模擬路線，確認接著會點擊彩虹瀑布入口。既有錄影則涵蓋從彩虹瀑布開啟同一張地圖的背景。

2026-10-12 實機驗證：使用實際主介面的「採收螢火草」按鈕，從淘淘樂街經漿果叢林地圖成功進入彩虹瀑布；「選擇應用程式」可選取並套用 Flash Player。帳號已達每日上限，因此未取得新獎勵。首次實測發現上限提示單次確認未關閉，改為最多三次確認、等待畫面回到瀑布後才完成；新版已驗證關閉遺留提示，以及重新採收後出現的上限提示。加入忽略首點與持續無法關閉的回歸案例，完整本機資料共 103 項檢查通過。實測版本位於 `撈金魚/bin/LiveFix/`；未測試購買、藥劑或戰鬥功能。

摩界之門採集使用 `ForestHarvest.Tests.csproj`，測試完整進圖、兩項分別計次及上限、遺留獎勵不計次、確認重試、錯誤物品／未知提示停止、地圖及採集逾時、載入中不重點、取消。

```powershell
MSBuild tests/ForestHarvest.Tests.csproj /verbosity:minimal
./tests/bin/ForestHarvest.Tests.exe .video-analysis/new-feature/normalized
```

影片 `2026-10-11 23-07-43.mkv` 使用 `fps=1,crop=1866:1080:0:0,scale=960:560` 正規化，11 個代表影格各驗證 720/960/1440 寬度。第一個參數之後可附加多組 `<狀態名稱> <實機截圖>`，例如 `SeedReward`、`MushroomReward`、`Limit`、`UnknownDialog`。包含四張實機截圖時共 57 項檢查通過。實機樣本先以與程式相同的縮放方式正規化，避免 960×559 與 960×560 的字體反鋸齒差異。
